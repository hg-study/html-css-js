# Tag

### Tag 정의

> Tag는 브라우저에게 콘텐츠를 어떻게 표시할지 지시하는 마크업 기호다. `<태그명>` 여는 태그와 `</태그명>` 닫는 태그 쌍으로 구성되며, 두 태그 사이의 내용 전체를 요소(Element) 라 한다. 닫는 태그 없이 혼자 사용하는 태그는 빈 요소(Empty Element) 라 한다. (예: `<br />, <hr />, <meta />`) 

<br>

## HTML 문서 기본 구조

| 태그 / 선언 | 역할 |
|---|---|
| `<!DOCTYPE html>` | 브라우저에게 HTML5 문서임을 선언. 반드시 문서 최상단에 위치 |
| `<html lang="ko">` | HTML 문서의 루트 요소. `lang` 속성으로 문서 기본 언어 명시 |
| `<head>` | 브라우저에 전달할 메타데이터 영역. 화면에 직접 표시되지 않음 |
| `<body>` | 실제 화면(ViewPort)에 표시되는 본문 영역 |

> **주석:** `<!-- 내용 -->` 형식. 브라우저가 무시하며 화면에 표시되지 않는다.

## Block vs Inline 요소

> HTML 요소는 레이아웃 동작 방식에 따라 두 종류로 나뉜다. 블록 태그는 줄 전체를 차지하므로, 기본적으로 인라인 태그 내부에 블록 태그를 포함할 수 없지만, HTML5부터 조건에 따른 예외 태그가 있다.  `<a> <ins> <del> <canvas> …`


| **구분** | **Block Tag** | **Inline Tag** |
| --- | --- | --- |
| 기본 동작 | **줄 전체**를 차지 | **내용만큼만** 차지 |
| 줄바꿈 | 태그 전후에 자동 줄바꿈 발생 | 줄바꿈 없음 |
| 너비/높이 지정 | width, height 지정 가능 | 기본적으로 지정 불가 |
| 레이아웃 | 구조 배치에 사용 | 텍스트 내부 강조나 기능에 사용 |
| 중첩 가능 | 블록 내부에 다른 블록/인라인 태그 포함 가능 | 인라인 내부엔 블록 태그 포함 불가 (HTML5에선 일부 허용됨) |
| 대표 태그 | `<h1~h6>`, `<p>`, `<div>`, `<ul>`, `<ol>`, `<li>` | `<span>`, `<a>`, `<strong>`, `<em>`, `<br>` |


 **Inline 요소의 제한:** 기본 상태에서 `width`, `height`, 상하 `margin` 이 적용되지 않는다. `display: block`을 적용하면 Inline 요소를 Block처럼 동작시킬 수 있다.

<br>

### Block Tag 예시

| **태그** | **설명** |
| --- | --- |
| `<div>` | 대표적. 문서 분할 태그 |
| `<p>` | 문단(Paragraph) 나누는 태그.<br>위아래에 기본 margin 자동 적용 |
| `<h1>` ~ `<h6>`| 제목(Heading) 태그 |
| `<ul>`, `<ol>`, `<li>` | 목록(List) 관련 태그 |
| `<section>`, `<article>`, `<header>`, `<footer>` | 시맨틱 블록 태그 |
| `<form>`, `<table>` | 폼, 표 관련 블록 태그 |

```html
<div>
	<h1>제목</h1>
	<p>단락</p>
</div>
```

<br>

### Inline Tag 예시

| **태그** | **설명** |
| --- | --- |
| `<span>` | 인라인 태그 |
| `<a>` | 다른 페이지 등 이동 하이퍼링크 태그 |
| `<img>` | 이미지 태그 |
| `<strong>`, `<em>` | 강조 태그 |
| `<label>`, `<input>`, `<select>`, `<textarea>` | 폼 관련 인라인 태그 |

```html
<div>
    <p><strong>주의:</strong>비밀번호는 8자 이상의 영문, 숫자 조합이어야 합니다.</p>
</div>
```

<br>

### display 속성

| 값 | 동작 |
|---|---|
| `block` | Block 요소로 변환. width · height · margin 전체 적용 가능 |
| `inline` | Inline 요소(기본값). width · height · 상하 margin 미적용 |
| `inline-block` | 줄 바꿈 없이 width · height 적용 가능 |
| `none` | 요소를 화면에서 완전히 숨김 |

## 주요 태그 상세

#### 제목 태그 `<h1> ~ <h6>`
- **Block 요소**. 숫자가 클수록 글자 크기·강조 감소
- `h1` 은 페이지당 1개 권장 (SEO · 접근성 기준)

<br>

#### 단락 태그 `<p>`
- **Block 요소**. 위아래에 기본 `margin` 자동 적용
- 텍스트 단락을 표현할 때 사용

<br>

#### 컨테이너 태그 `<div>` / `<span>`

| 태그 | 종류 | 용도 |
|---|---|---|
| `<div>` | Block | 여러 요소를 묶어 영역을 나누는 레이아웃 컨테이너 |
| `<span>` | Inline | 텍스트 일부를 묶어 스타일을 적용하는 인라인 컨테이너 |

> `<div>`와 `<span>` 자체는 시각적 의미가 없다. CSS와 함께 사용해 레이아웃·스타일을 적용한다.

<br>

#### 빈 요소 (Self-Closing)
내용(content)이 없고 여는 태그만 존재하는 태그

| 태그 | 역할 |
|---|---|
| `<br />` | 줄 바꿈 (Line Break) |
| `<hr />` | 수평 구분선 (Horizontal Rule). Block 요소 |
| `<meta />` | 메타데이터 |
| `<img />` | 이미지 삽입 |
| `<input />` | 입력 필드. `type` 속성값에 따라 입력 방식이 달라진다. |

<br>

#### `<input>` type 속성

| 값 | 동작 |
|---|---|
| `text` | 일반 텍스트를 입력받는 기본 필드 (기본값) |
| `password` | 입력값이 화면에 가려져(●●●) 표시되는 필드 |
| `file` | 사용자 기기에서 파일을 선택해 업로드할 수 있는 필드 |
| `email` | 이메일 형식 검증이 포함된 필드. `@` 포함 여부 등 브라우저 자체 유효성 검사 |
| `checkbox` | 여러 항목 중 다중 선택이 가능한 체크박스 |
| `radio` | `name` 속성이 같은 그룹 내에서 단일 선택만 가능한 버튼 |

<br>

### Form 관련 태그

`<input>`을 감싸 실제 데이터를 전송하는 폼 구성 태그들

| 태그 / 속성 | 종류 | 설명 |
|---|---|---|
| `<form action="">` | Block | 사용자 입력을 모아 서버로 전송하는 영역. `action`은 전송할 서버 측 경로(URL). 비워두면 현재 페이지 주소로 전송됨 |
| `<label>` | Inline | 입력 항목의 제목을 나타내는 텍스트 요소 |
| `<select>` | Inline-block | 여러 옵션 중 하나를 고르는 드롭다운 목록 |
| `<option value="">` | - | select 안의 개별 선택 항목. `value`는 폼 전송 시 서버로 실제 전달될 값. 비워두면 선택해도 빈 값이 전송됨 |
| `<button>` | Inline-block | 클릭 시 동작을 실행하는 버튼. `<form>` 내부에서는 기본 `type`이 `submit`이라 클릭 시 form 데이터를 전송 |
| `placeholder` | 속성 | 입력 전 빈 칸에 보여주는 미리보기 텍스트 |

<br>

### `<form>` method 속성

> 서버로 요청을 보낼 때 데이터를 전달하는 방식을 지정하는 속성이다.

<br>

| **값** | **설명** |
|---|---|
| `get` | 요청 정보를 Query String으로 전달한다 (기본값) |
| `post` | 요청 정보를 Request body(Payload)로 전달한다 |
| `put` | 리소스 전체를 새 데이터로 교체(덮어쓰기)할 때 사용한다 |
| `patch` | 리소스의 일부 데이터만 수정할 때 사용한다 |
| `delete` | 리소스를 삭제할 때 사용한다 |

### `<button>` vs `<input type="submit">`

> 둘 다 form 데이터를 전송하는 제출 버튼이지만 내부 구성 방식에 차이가 있다.

<br>

| **태그** | **설명** |
|---|---|
| `<button>` | 텍스트·이미지 등 HTML 요소를 내부에 넣을 수 있다. `<form>` 내부에서는 기본 `type`이 `submit`이라 클릭 시 form 데이터를 전송한다 |
| `<input type="submit">` | `value` 속성으로 버튼 텍스트를 지정한다. 내부에 HTML 요소는 넣을 수 없다 |

<br>

<span style="color:gray">스타일 자유도가 필요하면 `<button>`을, 단순 제출 버튼이면 둘 중 아무거나 써도 무관하다.</span>

<br>

### input 유효성 검사 속성

> 클라이언트(브라우저) 단에서 입력값을 검증해, 조건에 맞지 않으면 `submit`을 막는 속성들이다.

<br>

| **속성** | **설명** |
|---|---|
| `required` | 값이 비어있으면 submit을 막고 브라우저가 자동으로 에러 메시지를 표시한다 |
| `pattern` | 정규식을 지정해 입력값이 해당 형식과 일치하지 않으면 submit을 막는다 |
| `title` | `pattern` 검증 실패 시 브라우저가 표시할 안내 문구를 지정한다 |
| `readonly` | 입력은 불가능하지만 서버 전송 대상에는 포함된다 |
| `disabled` | 입력이 불가능하고 서버 전송 대상에서도 제외된다 |

<br>

<span style="color:gray">`readonly`는 우편번호 검색 후 자동으로 채워지는 주소 필드처럼 값은 유지한 채 수정만 막을 때 사용하고, `disabled`는 조건이 충족되기 전까지 완전히 비활성화할 때 사용한다.</span>

<br>

- 예제 코드: [회원가입 폼 페이지2 유효성 검사 준비](../22Form_Validation.html)

## CSS Box Model

모든 HTML 요소는 아래 4개의 영역으로 공간이 구성된다.

```
┌─────────────────────────────┐
│          margin             │  ← margin: 바깥 여백 (다른 요소와의 간격)
│  ┌───────────────────────┐  │
│  │        border         │  │  ← border: 테두리 선
│  │  ┌─────────────────┐  │  │
│  │  │     padding     │  │  │  ← padding: 안쪽 여백 (content ↔ border)
│  │  │  ┌───────────┐  │  │  │
│  │  │  │  content  │  │  │  │  ← content: 실제 콘텐츠 (텍스트, 이미지 등)
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

| CSS 속성 | 설명 |
|---|---|
| `background-color` | 배경색 지정 |
| `width` / `height` | 너비 / 높이 (content 영역 기준) |
| `border` | 테두리. `두께 스타일 색` 순 작성 (예: `1px solid blue`) |
| `padding` | 안쪽 여백 |
| `margin` | 바깥쪽 여백 |

> **Inline 요소**는 Box Model에서 `width`, `height`, 상하 `margin`이 적용되지 않는다.

## 리스트 태그

#### 기본 구조

| 태그 | 이름 | 설명 |
|---|---|---|
| `<ul>` | Unordered List | 순서 없는 목록. 기본 마커: 점(•) |
| `<ol>` | Ordered List | 순서 있는 목록. 기본 마커: 숫자(1, 2, 3...) |
| `<li>` | List Item | ul 또는 ol의 개별 항목. 반드시 ul/ol 내부에서만 사용 |

> `ul`과 `ol` 모두 **Block 요소**이며, 기본적으로 들여쓰기(padding-left)가 자동 적용된다.

<br>

### `<ol>` type 속성 - 마커 형식 변경

| 값 | 마커 |
|---|---|
| `1` | 숫자 (기본값) |
| `a` | 소문자 알파벳 |
| `A` | 대문자 알파벳 |
| `i` | 소문자 로마 숫자 |
| `I` | 대문자 로마 숫자 |

<br>

### `<ol>` 추가 속성

| 속성 | 설명 |
|---|---|
| `start="숫자"` | 시작 번호를 지정 (예: `start="3"` → 3, 4, 5...) |
| `reversed` | 번호를 역순으로 표시 |

<br>

### 중첩 리스트
`<li>` 내부에 또 다른 `<ul>` 또는 `<ol>`을 삽입해 계층 구조를 표현한다.

```
ul (대분류)
├── li
│   └── ol (순서 있는 세부 항목)
│       ├── li
│       └── li
└── li
    └── ul (순서 없는 세부 항목)
        └── li
```

- 세부 항목이 **순서를 가질 때** → `ol` 중첩
- 세부 항목이 **순서 무관할 때** → `ul` 중첩
- 들여쓰기 depth에 따라 마커 모양이 자동으로 달라진다.
  
  <br>
