# Operator

### 연산자

> 값을 계산하거나 비교하는 기호다. 피연산자의 개수에 따라 단항, 이항, 삼항으로 나눈다.

<br>

| **구분** | **연산자** | **설명** |
| --- | --- | --- |
| 산술 | `+` `-` `*` `/` `%` `**` | 사칙연산, 나머지, 거듭제곱 |
| 증감 | `++` `--` | 1 증가, 1 감소. 앞에 붙이면 먼저 계산하고(`++a`), 뒤에 붙이면 나중에 계산한다(`a++`) |
| 할당 | `=` `+=` `-=` `*=` `/=` `%=` | 오른쪽 값을 왼쪽 변수에 대입. `a += 1`은 `a = a + 1` |
| 비교 | `==` `!=` `===` `!==` `>` `<` `>=` `<=` | 결과는 `true` 또는 `false`. `===`는 값과 타입을 모두 비교하고 `==`는 타입을 변환해 비교 |
| 논리 | `&&` `\|\|` `!` | AND, OR, NOT. `&&`는 둘 다 참, `\|\|`는 하나라도 참 |
| 삼항 | `조건 ? 참 : 거짓` | 조건에 따라 두 값 중 하나를 선택 |

<br>

<span style="color:brown">`==`는 `"1" == 1`을 `true`로 판단한다. 타입 변환에 따른 오류를 막기 위해 `===`를 기본으로 사용한다.</span>

<br>

```javascript
let w = window.innerWidth;
let mode = (w < 380) ? "mobile" : "desktop";   // 삼항 연산자
```
